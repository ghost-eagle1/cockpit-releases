# Cockpit — releases

Downloads and release notes for the Cockpit desktop app. The app checks this repository for updates automatically.

- **Latest version:** see [Releases](https://github.com/ghost-eagle1/cockpit-releases/releases/latest)
- **Windows:** `Cockpit-Setup-x.y.z.exe` (updates install automatically)
- **macOS:** `Cockpit-x.y.z-universal.dmg` (drag to Applications)
- **Found a problem?** [Open an issue](https://github.com/ghost-eagle1/cockpit-releases/issues/new/choose)
